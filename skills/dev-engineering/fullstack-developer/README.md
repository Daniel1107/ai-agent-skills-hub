# fullstack-developer

- 分类：全栈工程与技术开发 (dev-engineering)
- 来源等级：external-fallback
- 来源地址：https://github.com/Shubhamsaboo/awesome-llm-apps
- 安装类型：npx-skills
- 风险等级：high
- 当前状态：indexed

## 推荐安装命令

```bash
npx skills add https://github.com/Shubhamsaboo/awesome-llm-apps --skill fullstack-developer
```

## 维护要求

1. 安装前先确认来源仓库、提交历史、许可证和脚本权限。
2. 高风险 Skill 必须先在隔离环境试装。
3. 若来源迁移到 OpenAI 官方插件仓库，优先更新 `skills.json` 的 `sourceLevel` 和 `source`。
4. 不在本目录保存 Token、Cookie、私钥或账户凭据。
